# Criando Sites - Landing Page

Landing page de alta conversão desenvolvida para transformar visitantes em leads e vendas. Construída com tecnologias modernas para performance e impacto visual.

## Autor

Desenvolvido por **isaquesantosdev.com**

## Visão Geral

Este projeto é uma landing page de alta performance projetada para agências digitais e freelancers. Apresenta uma estética "Cósmica" com animações avançadas, efeitos de glassmorphism e um layout responsivo que se adapta a todos os dispositivos.

## Funcionalidades

- **Seção Hero de Alto Impacto**: Imagens hero dinâmicas e rotativas com animações flutuantes e tipografia em gradiente.
- **Navegação Responsiva**: Barra de navegação com glassmorphism que se adapta a telas móveis e desktop.
- **Sistema de Design Moderno**: Configuração personalizada do Tailwind CSS com uma paleta de cores cósmica e tipografia profissional (Poppins).
- **Elementos Interativos**: Efeitos de hover, rolagem suave e sequências de entrada animadas usando Framer Motion.
- **Geração de Leads**: Botões de Call-to-Action (CTA) estrategicamente posicionados integrados com WhatsApp para conversão direta.
- **Otimizado para Performance**: Construído com Vite para carregamento rápido e otimização dos Core Web Vitals.

## Tecnologias

- **React**: Biblioteca de UI
- **TypeScript**: Tipagem estática para robustez
- **Vite**: Ferramenta de frontend de nova geração
- **Tailwind CSS**: Framework CSS utility-first
- **Shadcn UI**: Primitivos de componentes acessíveis
- **Framer Motion**: Biblioteca de animação pronta para produção

## Início Rápido

Siga estes passos para configurar o projeto localmente:

1.  **Clonar o repositório**
    ```bash
    git clone <url-do-repositorio>
    cd criandosites
    ```

2.  **Instalar dependências**
    ```bash
    npm install
    ```

3.  **Iniciar o servidor de desenvolvimento**
    ```bash
    npm run dev
    ```

4.  **Abrir no navegador**
    Navegue para `http://localhost:8080` para visualizar a aplicação.

## Configuração

O projeto utiliza uma configuração padrão `.env` (se aplicável) e constantes customizáveis.

| Comando | Descrição |
|---------|-----------|
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Compila a aplicação para produção |
| `npm run lint` | Executa o linter para garantir qualidade de código |
| `npm run preview` | Visualiza a build de produção localmente |

## Estrutura

- `src/components`: Componentes de UI reutilizáveis e seções da landing page.
- `src/pages`: Páginas principais da aplicação (Index, NotFound).
- `src/assets`: Assets estáticos incluindo imagens hero.
- `src/lib`: Funções utilitárias e classes auxiliares.
